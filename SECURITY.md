# Security

Please do not open public issues for security-sensitive findings, such as a key, credential or other secret that may have slipped into an index.

Report them privately through GitHub: **Security → Report a vulnerability** on this repository. Reports are reviewed promptly, and any confirmed secret is removed from the index and from the git history.

This project does not accept reports about vulnerabilities in the vendor's own firmware; send those to the vendor's security team.
