What is here:
- Scripts written for this project (MIT, see LICENSE).
- Indexes derived from tvOS 26.6: file paths, bundle identifiers, class, protocol, method and property names with their declared signatures, and numeric animation parameters.

What is not here, by design:
- No Apple binaries, firmware images, dyld caches, decompiled or disassembled code, class-dump header files, images, `Assets.car` files, `.ca` packages or other artwork.

To reproduce the indexes, use your own copy of the IPSW with `scripts/reproduce.sh`. Everything it extracts stays in a git-ignored `.work/` directory.
